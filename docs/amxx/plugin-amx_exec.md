# amx_exec

## Description

Allows server administrators to execute commands on behalf of players. The plugin lets you run client commands as if the player typed them. With great power comes great responsibility - this can be used to manipulate player actions. Should be used carefully and never abused.

* https://forums.alliedmods.net/showthread.php?t=13211
